# paicad 변경 기록

버전 정책: geometry-engine.md §17. `src/paicad/__init__.py`의 `__version__`이 단일 출처이고, `packages/paicad/**` 를 바꾸는 커밋마다 버전을 올리고 이 파일 최상단에 항목을 추가한다.

## 0.4.0 — 2026-10-19
- 변경: (A) 위치형 파라미터(`HOLE_POS_U`/`HOLE_POS_V`) 기본 범위 = 절대 mm. 새 옵션 `extract.position_range_mm`(기본 5.0, > 0 유한) → extract가 `parameter_features.json` 위치형 `range`를 공칭 ± 5 mm(`feasible`로 자름)로 쓰고 키는 `{"min","max","mm"}`(치수형은 기존 `range_ratio`, `{"min","max","ratio"}`). `parameter_extracted.xml`은 범위가 없어 불변. (B) envelope 스윕: 위치형은 mm 단계 `--pos-steps`(기본 `1,2,3,5,8,10` mm, ± 양방향, `--stop-after-fail` 기본 2 연속 실패 중단), 치수형은 기존 `--steps` %. 행에 `step`·`unit`(`%`|`mm`) 추가(`pct`는 % 행만, mm 행은 null), 요약에 `unit`·`last_ok`·`first_fail`·`last_ok_label`·`first_fail_label`("3 mm"/"20 %"), `last_ok_pct`·`first_fail_pct`는 % 파라미터만(mm 파라미터는 null), `envelope.json` 최상위 `pos_steps_mm`, `limit_metric`에 `at`·`unit`. `feasible`(source envelope) = 위치형은 공칭 ± last_ok mm. `envelope.csv` 열 `step`·`unit` 추가. `report_envelope.csv` 열 `unit` 추가·`last_ok_pct_*`/`first_fail_pct_*` → `last_ok_*`/`first_fail_*`(값에 단위 포함, 호환 깨짐 — 사람용 보고서), `report_envelope.md` 표에 단위 열·단위 붙은 값. selftest 짧은 envelope `--envelope-pos-steps`(기본 `1,3` mm), 보고서 단위 표시. (C) update 피처 충돌 사전 검사(`collision.py`, OCP 미사용): 계획된 면 이동으로 재구성 전에 (1) 이동 영향을 받는 평면 면의 와이어(외곽·구멍·리브 발자국·포켓 입구)를 이웃 면의 면내 이동으로 예측해 와이어끼리 교차·근접(≤ 바디 tol)·내부 와이어의 외곽 이탈 = `BOUNDARY_OVERLAP`(구멍↔리브/벽, 포켓↔리브 등), (2) 와이어 자기교차·방향 반전 = `SELF_INTERSECTION`, (3) 투영이 겹치는 반대 방향 평행 평면 쌍의 두께·틈 ≤ tol(부호 바뀜) = `WALL_PENETRATION`. 공칭에서 이미 걸리는 쌍은 제외. 충돌 → 새 실패 코드 `GEOM_FEATURE_COLLISION`(category `CAD_FAILED`, 종료코드 10), `update.json` 선택 키 `collisions[{kind,face,other,features,detail,body}]`, check까지 가지 않음(sweep 행 `fail_code`도 같음).
- 영향: 판정 결과 변경. 가상 쿠션: `CUSH_R_HOLE_U_1` −20 %(86.4 mm, 구멍이 리브 발자국과 겹침)가 update에서 `GEOM_FEATURE_COLLISION`(0.3.0: update 통과 후 check 퇴화 삼각형 또는 BRepCheck `GEOM_CAD_FAILED`). 이전 `GEOM_CAD_FAILED`/`GEOM_TOPOLOGY_CHANGED`였던 포켓 바닥 관통(`POCKET_D` 25)·베이스 얇아짐(`THK_3` 7)·리브 두께 0·`THK_1` −20 %(리브가 외곽 밖)은 `GEOM_FEATURE_COLLISION`. 가상 쿠션 envelope 재측정(기본 옵션, 위치형 mm): `CUSH_L_HOLE_U_1` +5/−3 mm(첫 실패 +8 QUALITY, −5 QUALITY), `CUSH_L_HOLE_V_1` +5/−3 mm(+8, −5 QUALITY), `CUSH_R_HOLE_U_1` +3/−5 mm(+5, −8 QUALITY; +8·−10은 COLLISION), 치수형 last_ok는 0.3.0과 같음(실패 코드만 CAD_FAILED→COLLISION). extract 위치형 `range` 변경, 그 밖의 extract·tag 결과 불변. `engine_version` 0.4.0
- 계약: geometry-engine.md §4.3(위치형 range)·§4.6(update.json `collisions`)·§4.9(`extract.position_range_mm`)·§5.3(`--pos-steps`)·§6.3(충돌 사전 검사)·§6.5 실패 코드 표(`GEOM_FEATURE_COLLISION`)·§11.2(mm 단계·단위)·§17 — 계약 본문 미반영(변경 메모 요청 필요)

## 0.3.0 — 2026-10-19
- 변경: (A) 품질 판정 기준 변경(사용자 확정). `options.quality` 기본값 `min_edge_mm: null`(선택 절대 하한, null = 끔), `min_edge_ratio: 0.8`(baseline 무변형 최소 엣지 대비), 새 키 `dt_ratio_min: 0.8`(baseline Δt 추정 대비 — tetra 특성 길이 h = 3V/최대 면적, component별 최소 h 비의 최솟값). stretch ≥ 0.1·경계 삼각형 aspect ≤ 10은 절대 기준 유지. `BASELINE_QUALITY_BELOW`는 baseline이 절대 기준(반전·stretch·aspect) 미달일 때만. 옵션 범위 검사 추가(quality 키·`position_ref`). (B) 위치형 파라미터(HOLE_POS_U/V) 기준 `position_ref`: `nearest_fixed`(기본, 이번 샘플에서 그 축 방향으로 이동하지 않는 축 수직 평면 중 가장 가까운 면까지 거리 유지, 동률이면 면적 큰 면→낮은 id, 값 변화는 +축 방향 이동) | `proportional`(바디 길이 비례). 고정 면이 없으면 proportional + 경고 `POS_REF_NO_FIXED_FACE`. (C) 단계 3: `paicad run`(update→morph→check, 첫 실패에서 중단, 단계별 보고·로그는 각 폴더, `--check-dir/run.json`에 단계 기록과 실패 시 `skip{code,category,message,step,report}`, 종료코드 = 실패 단계 종료코드, 마지막 줄 `PAICAD RESULT <PASS|FAIL> <code|-> run.json`, 출력 존재 시 시작 전 `GEOM_OUTPUT_EXISTS`), `writers/` 레지스트리(§18.3, `--solver` 기본 `radioss`·유일 구현, morph·run 인자), envelope 보고서 `report_envelope.md`·`report_envelope.csv`(sweep 출력, 파라미터별 last_ok·first_fail·지배 지표 = 여유(값/기준) 최소 기준), `paicad selftest` 최소판(extract→tag→공칭 update/morph/check→짧은 envelope, `selftest_report.json`·`.md` = 수치만: 태깅 미분류 수·match_ratio, 무변경 왕복 바이트 동일(writer·공칭 morph), 공칭 check 지표, envelope 요약; 작업 파일은 `<out-dir>/work/`). check (a) 재측정이 update의 의도 값(`expected`)과 비교. 품질 지표가 비유한(퇴화 삼각형)이면 null(이전: JSON 쓰기 GEOM_INTERNAL).
- 영향: 판정 결과 변경 — 가상 쿠션 baseline이 기본 옵션으로 check PASS(baseline 최소 엣지 0.749 mm, 이전 기본 1.0 mm로는 FAIL), L(`CUSH_L_THK_2`) +10%에서 미러 바디 구멍이 리브와 충돌하던 `GEOM_CAD_FAILED` 해소(샘플별 HOLE_U 측정값이 바뀔 수 있음 → `update.json` `positions[].expected_measured`). 출력 추가: `update.json` `positions`, `check.json` quality `edge_ratio`·`min_char_len_mm`·`baseline_min_char_len_mm`(`dt_ratio` 의미 = Δt 추정 비, 이전 = 최소 엣지 비), param 항목 선택 키 `expected`, envelope 행 `dt_ratio`·`param_margin`·요약 `limit_metric`, csv 열 `dt_ratio`. 새 명령 `run`·`selftest`, 새 파일 `run.json`·`report_envelope.*`·`selftest_report.*`. extract·tag 결과 불변. `engine_version` 0.3.0
