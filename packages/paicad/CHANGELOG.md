# paicad 변경 기록

버전 정책: geometry-engine.md §17. `src/paicad/__init__.py`의 `__version__`이 단일 출처이고, `packages/paicad/**` 를 바꾸는 커밋마다 버전을 올리고 이 파일 최상단에 항목을 추가한다.

## 0.3.0 — 2026-10-19
- 변경: (A) 품질 판정 기준 변경(사용자 확정). `options.quality` 기본값 `min_edge_mm: null`(선택 절대 하한, null = 끔), `min_edge_ratio: 0.8`(baseline 무변형 최소 엣지 대비), 새 키 `dt_ratio_min: 0.8`(baseline Δt 추정 대비 — tetra 특성 길이 h = 3V/최대 면적, component별 최소 h 비의 최솟값). stretch ≥ 0.1·경계 삼각형 aspect ≤ 10은 절대 기준 유지. `BASELINE_QUALITY_BELOW`는 baseline이 절대 기준(반전·stretch·aspect) 미달일 때만. 옵션 범위 검사 추가(quality 키·`position_ref`). (B) 위치형 파라미터(HOLE_POS_U/V) 기준 `position_ref`: `nearest_fixed`(기본, 이번 샘플에서 그 축 방향으로 이동하지 않는 축 수직 평면 중 가장 가까운 면까지 거리 유지, 동률이면 면적 큰 면→낮은 id, 값 변화는 +축 방향 이동) | `proportional`(바디 길이 비례). 고정 면이 없으면 proportional + 경고 `POS_REF_NO_FIXED_FACE`. (C) 단계 3: `paicad run`(update→morph→check, 첫 실패에서 중단, 단계별 보고·로그는 각 폴더, `--check-dir/run.json`에 단계 기록과 실패 시 `skip{code,category,message,step,report}`, 종료코드 = 실패 단계 종료코드, 마지막 줄 `PAICAD RESULT <PASS|FAIL> <code|-> run.json`, 출력 존재 시 시작 전 `GEOM_OUTPUT_EXISTS`), `writers/` 레지스트리(§18.3, `--solver` 기본 `radioss`·유일 구현, morph·run 인자), envelope 보고서 `report_envelope.md`·`report_envelope.csv`(sweep 출력, 파라미터별 last_ok·first_fail·지배 지표 = 여유(값/기준) 최소 기준), `paicad selftest` 최소판(extract→tag→공칭 update/morph/check→짧은 envelope, `selftest_report.json`·`.md` = 수치만: 태깅 미분류 수·match_ratio, 무변경 왕복 바이트 동일(writer·공칭 morph), 공칭 check 지표, envelope 요약; 작업 파일은 `<out-dir>/work/`). check (a) 재측정이 update의 의도 값(`expected`)과 비교. 품질 지표가 비유한(퇴화 삼각형)이면 null(이전: JSON 쓰기 GEOM_INTERNAL).
- 영향: 판정 결과 변경 — 가상 쿠션 baseline이 기본 옵션으로 check PASS(baseline 최소 엣지 0.749 mm, 이전 기본 1.0 mm로는 FAIL), L(`CUSH_L_THK_2`) +10%에서 미러 바디 구멍이 리브와 충돌하던 `GEOM_CAD_FAILED` 해소(샘플별 HOLE_U 측정값이 바뀔 수 있음 → `update.json` `positions[].expected_measured`). 출력 추가: `update.json` `positions`, `check.json` quality `edge_ratio`·`min_char_len_mm`·`baseline_min_char_len_mm`(`dt_ratio` 의미 = Δt 추정 비, 이전 = 최소 엣지 비), param 항목 선택 키 `expected`, envelope 행 `dt_ratio`·`param_margin`·요약 `limit_metric`, csv 열 `dt_ratio`. 새 명령 `run`·`selftest`, 새 파일 `run.json`·`report_envelope.*`·`selftest_report.*`. extract·tag 결과 불변. `engine_version` 0.3.0

- 영향: 출력 추가(update/morph/check/sweep). extract·tag 결과 불변. 보고 JSON `engine_version` 0.2.0. `face_map.json` 바디 항목에 선택 키 `uv_fallback`(정규화 (u,v) 매핑이 무효인 면 = 매개변수화 교체 또는 내부 와이어의 정규화 위치 변화)
