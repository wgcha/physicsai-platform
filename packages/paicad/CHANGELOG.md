# paicad 변경 기록

- 영향: 새 명령 `props scan|apply`·`map`, 새 파일 `props.json`·`props_apply.json`·`param_map.json`·`features/*.png`. `parameter_features.json`에 `adjacent_surfaces`·`png` 경로(이전 null + `PNG_RENDER_FAILED` 경고 없어짐), 옵션 사용값(check.json·envelope.json `options`)에 `map` 절 → `sweep_id` 바뀜. 판정 변경 가능: 퇴화(비유한) 품질 값만으로 FAIL이던 샘플이 PASS 가능(반전 요소는 계속 FAIL), 정밀도를 잃던 지수 표기·자유 형식 토큰 붙음이 이제 `GEOM_INC_FORMAT`, 좁은 필드에서 실패하던 값 일부가 쓰임. 표준 열 baseline의 형상·좌표·envelope 수치 불변(G1 보고서는 머리 2줄만 바뀜). `engine_version` 0.6.0
